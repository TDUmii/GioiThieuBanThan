# Easter egg assets

Reused from the owner's local Meow-Login project on 2026-10-01. Only these individual assets and the relevant license are included, not the reference project or its controller.

- `cat-rest.webp` and `cat-meow.webp`: original transparent calico character frames generated for Meow-Login with OpenAI's built-in image tool on 2026-09-03. Round watercolor-gouache cat, warm coat patches, hand-inked outline. The original reference picture is not redistributed. Eyes have small code-native pupils layered over the intended blank eye whites.
- `cat-paw.webp`: original AI-assisted transparent watercolor paw from Meow-Login. Its reaching-from-behind interaction is inspired by Hannah Goodridge's Cat Paw button. The implementation here is independent and finite, using two raster layers rather than the reference project's pointer-following arm controller. Original attribution: https://codepen.io/HannahG/pen/019f8fb8-b31f-7027-bcc6-0f15214de112 and https://hannahgoodridge.dev/playground/get-started-cat. The associated MIT notice is retained in `LICENSE-CAT-PAW.txt`.
- `meow.ogg`: George Miquilena, https://commons.wikimedia.org/wiki/File:Maullido_de_gata_hembra_joven.ogg, CC0 1.0 / public-domain dedication. Copied unchanged from the local source.
- `meow.mp3`: local MP3 fallback previously transcoded by Meow-Login; repeats the original sound twice with a short gap. The browser prefers the single original OGG clip when supported.

No new image generation, external image download or external audio service is used by this portfolio. All assets are served locally. Meowing requires explicit activation of the cat button; hover never plays audio. The mute choice lasts only for the current page view.
